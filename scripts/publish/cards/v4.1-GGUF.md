# LFM3-VL-2B-AndroidAgent-v4.1-GGUF

Phone format of [LFM3-VL-2B-AndroidAgent-v4.1](https://huggingface.co/alpharomercoma/LFM3-VL-2B-AndroidAgent-v4.1) for llama.cpp.

| File | What |
|---|---|
| `LFM3-VL-2B-AndroidAgent-v4.1-Q4_K_M.gguf` | Language model, 4-bit (Q4_K_M) |
| `mmproj-LFM3-VL-2B-Q8_0.gguf` | Vision projector, unchanged from [LiquidAI/LFM3-VL-2B-GGUF](https://huggingface.co/LiquidAI/LFM3-VL-2B-GGUF) (the fine-tune did not touch the vision tower) |

Made with llama.cpp `cd959bae9` (`convert_hf_to_gguf.py` → F16 → `llama-quantize Q4_K_M`); the same procedure reproduces
v4's GGUF byte for byte.

## Serving (as in our evaluations)

```bash
llama-server -m LFM3-VL-2B-AndroidAgent-v4.1-Q4_K_M.gguf --mmproj mmproj-LFM3-VL-2B-Q8_0.gguf \
  -c 8192 --image-max-tokens 1024 --reasoning-format deepseek -np 1 -ngl 99
```

Prompt and output format: see the [model card](https://huggingface.co/alpharomercoma/LFM3-VL-2B-AndroidAgent-v4.1).

## Limitations

- Research model. Do not let it act unattended on a phone with real accounts, messages or payments.
- English goals, one screenshot per step, no memory beyond the 8-step text history.
- Trained only on recorded demonstrations; it has never interacted with a live phone during training.
